# :fire: The Forge :fire: 

This directory contains several modules ranging from basic hardware design up to complicate systems. The goal is to enforce the fundamentals and develop skills in making more complex designs. To whoever goes through all these challenges is gauranteed to have mastered the art of digital design.

There are different phases marked by `pN` where `N` is the phase number. Start with phase `N=1` all the way until the last phase. In each phase, there are exercises marked as `eX` where `X` is the exercise number. It is a must that one must do these in chronological order.

# Other Considerations
- One needs to be at least familiar with the concept of hardware description languages (HDL).
- You can learn the basics online.
- Not all test benches have complete test cases. Only the basic ones or easy to implement ones. The rest are given to you as an exercise.
